# Zumar Arshad | Frontend Developer Portfolio

A personal portfolio website for **Zumar Arshad**, a Frontend Developer specializing in responsive websites, custom WordPress themes, and Shopify stores.

🔗 **Live Site:** [your-link-here](#)

## Built With
- HTML5 / CSS3 (SCSS-style architecture)
- JavaScript (vanilla)
- [Bootstrap 5.3.3](https://getbootstrap.com/) & [Bootstrap Icons](https://icons.getbootstrap.com/)
- [GSAP](https://gsap.com/) for scroll/UI animations
- Google Fonts — DM Sans & Playfair Display

## Features
- **Hero / Home** — introduction and quick call to action
- **About** — background and personal introduction
- **Services** — Frontend Development, WordPress Development, Shopify Development, Performance & UI
- **Skills** — animated skill bars and a technology strip (HTML5, CSS3, SCSS, JavaScript, Bootstrap, WordPress, PHP, Shopify, Liquid, Git, GitHub, GSAP)
- **Projects** — showcase of live work, including Aventra, Pawfy, and Rodio websites
- **Experience & Education** — work history at GFXpartner and IT Oasis
- **Contact** — contact form plus direct email/social links
- Fully responsive layout with smooth scroll-reveal animations
- Downloadable resume (`assets/Zumar_Arshad_Resume.pdf`)

## Setup
```bash
git clone https://github.com/ZumarArshad/Zumar_Arshad_Portfolio.git
cd Zumar_Arshad_Portfolio
open index.html
```
No build step or dependencies are required — it's a static HTML/CSS/JS site that runs directly in the browser.
